# Vietnam Travel Website

Website khám phá du lịch các tỉnh thành Việt Nam.

## Công nghệ sử dụng

- Laravel 12
- PHP 8.2
- MySQL
- HTML, CSS, JavaScript
- XAMPP

## Chức năng dự kiến

- Đăng ký, đăng nhập
- Tìm kiếm tỉnh/thành
- Xem địa điểm du lịch
- Đánh giá và bình luận
- Yêu thích địa điểm
- Tạo lịch trình du lịch
- Thống kê dữ liệu
- Gợi ý địa điểm bằng AI
- Chatbot hỗ trợ du lịch
